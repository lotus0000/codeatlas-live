# Plan 4 — Viewer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A React viewer, served by the collector, that shows recent activity, the execution tree with its evidence kinds and gaps, a span inspector with verified source in Monaco (open in IDE, copy path:line), and the Explain Execution tab, live and in light and dark themes.

**Architecture:** The collector already builds everything the viewer shows: `GET api/traces` (summaries), `GET api/traces/{id}` (tree with kinds, evidence, gaps and Explain lines), `GET api/source` (verified source), `POST api/open`, and the SignalR hub `/live`, which pushes `traces-updated` summaries. The viewer adds no execution facts of its own. It merges summaries, follows the newest trace that reached the backend, refetches the selected trace when it changes, and lays out what the collector returned. The viewer lives in `src/viewer`. `scripts/build-viewer.sh` builds it into `src/CodeAtlas.Collector/wwwroot`, which is git-ignored. Until that has run, the collector serves a one-line "how to build the viewer" page at `/`. The viewer's test fixtures are real collector responses, produced by a collector test that fails when the two drift apart.

**Tech Stack:**
- Frontend: React 19.3, TypeScript ~6.0.2, Vite 8.3, Tailwind CSS 4.3, shadcn/ui 4.21 (style `radix-nova`, generated by the shadcn CLI), lucide-react.
- Code and fonts: Monaco 0.57 (bundled), Geist and Geist Mono via Fontsource (bundled).
- Live updates: `@microsoft/signalr` 10.0.
- Tests: Vitest 5, Testing Library, jsdom.
- Collector side: .NET 10, xUnit v3.

**Spec:** `docs/superpowers/specs/2026-10-10-codeatlas-live-mvp-design.md` (§2 principles, §7.2 evidence kinds, §7.5 security, §8 viewer). The approved visual direction is the three-board mockup: dark zinc, Geist, the Execution / Explain / Failure boards.

## Global Constraints

- **Location and dependencies**
  - The viewer lives in `src/viewer/`.
  - Dependencies are pinned to exact versions (as listed in Task 2), except `typescript` at `~6.0.2`, which matches `src/web`.
- **No outbound requests (§7.5):**
  - Monaco, its worker and the fonts are bundled.
  - The built output must not reference a CDN (`fonts.googleapis`, `fonts.gstatic`, `cdn.jsdelivr`, `unpkg.com`, `cdnjs`).
- **Path base:**
  - Every URL the viewer requests is relative to `document.baseURI`, and Vite `base` is `'./'`.
  - The viewer must work under a path base such as `/absproxy/4318/`.
- **Evidence only (§2.1):**
  - The tree, gap messages and Explain sentences are shown exactly as the collector sent them.
  - The viewer never creates a node, an edge or a sentence about execution.
- **The four evidence kinds are always visually distinct (§7.2):**
  - **Executed:** a solid node.
  - **Routing metadata:** a "route → X" chip on the endpoint node, never a node of its own.
  - **Heuristic:** a dashed edge plus a "heuristic" badge.
  - **Gap:** an amber note, worded as unknown.
- **Themes:**
  - Light and dark, defaulting to the system setting.
  - The choice is remembered in `localStorage` under `codeatlas.theme`, and every storage access is wrapped in `try/catch`.
- **UI components:**
  - Controls come from shadcn/ui (the maintainer preference).
  - Generated `src/components/ui/*` files come only from the shadcn CLI and are never hand-edited.
- **Slow spans:** ≥ 200 ms by default; `?slow=<ms>` in the viewer URL overrides it (spec §8, "configurable").
- **Opening source:**
  - Files open only through `POST api/open`, with the session token from `GET api/session`.
  - The viewer sends the method identity (`assembly`, `mvid`, `token`) and never a path.
- **UI text:** English (developer tool).

## Review Focus

- **A trace keeps changing after it is selected.** Spans of the selected trace arrive while it is on screen. The view must refresh, and the selected span must stay selected → Task 5 test `a live update of the selected trace refetches it and keeps the selected span`.
- **The collector restarts.** The live connection drops and comes back, so the list must reload. The old session token is then rejected, so "Open" must fetch a new token and retry once → Task 5 test `reconnecting reloads the list`, Task 2 test `openInEditor fetches a new token and retries once after a 401`.
- **Very deep chains** (up to 2,000 spans) must stay readable: indentation is capped while `aria-level` keeps the real depth → Task 4 test `deep chains cap their indentation`.
- **Fast switching between traces.** A slow response for a trace that is no longer selected must not replace the current one → Task 5 test `a late response for a previously selected trace is ignored`.
- **Nanosecond timestamps beyond 2^53.** Two spans 1 µs apart at a 2023 epoch must keep their order and their exact offset (BigInt, not Number) → Task 3 test `offsets keep microsecond precision at real epochs`.

```ts
import type { CodeRef, CollectorInfo, OpenResult, SourceResponse, TraceSummary, TraceView } from './types'

/** Every request is relative to the page, so the viewer works under a path base such as /absproxy/4318/. */
export const apiUrl = (path: string) => new URL(path, document.baseURI).href

export class ApiError extends Error {
  constructor(message: string, readonly status: number) {
    super(message)
  }
}

async function problem(response: Response): Promise<ApiError> {
  let message = `HTTP ${response.status}`
  try {
    const body = (await response.json()) as { detail?: string; title?: string }
    message = body.detail ?? body.title ?? message
  } catch {
    // not JSON: keep the status text
  }
  return new ApiError(message, response.status)
}

async function getJson<T>(path: string): Promise<T> {
  const response = await fetch(apiUrl(path), { headers: { accept: 'application/json' } })
  if (!response.ok) throw await problem(response)
  return (await response.json()) as T
```

```ts
import { apiUrl } from './client'
import type { TraceSummary } from './types'

export type LiveState = 'connecting' | 'live' | 'offline'

/** Pushes summaries of traces that changed. `start` returns a stop function. */
export interface LiveSource {
  start(onUpdate: (summaries: TraceSummary[]) => void, onState: (state: LiveState) => void): () => void
}

export const signalRLive: LiveSource = {
  start(onUpdate, onState) {
    const connection = new HubConnectionBuilder()
      .withUrl(apiUrl('live'))
      .withAutomaticReconnect({ nextRetryDelayInMilliseconds: () => 2000 })
      .configureLogging(LogLevel.None)
      .build()
    connection.on('traces-updated', onUpdate)
    connection.onreconnecting(() => onState('connecting'))
    connection.onreconnected(() => onState('live'))
    let stopped = false
    let retry: ReturnType<typeof setTimeout> | undefined
    // Automatic reconnect covers dropped connections; a failed first start (collector restarting) is retried here.
    const begin = async () => {
      onState('connecting')
      try {
        await connection.start()
        if (!stopped) onState('live')
      } catch {
        if (stopped) return
        onState('offline')
        retry = setTimeout(() => void begin(), 2000)
      }
    }
    connection.onclose(() => {
      if (stopped) return
      onState('offline')
      retry = setTimeout(() => void begin(), 2000)
    })
    void begin()
    return () => {
      stopped = true
      clearTimeout(retry)
      void connection.stop()
    }
  },
}
```

```ts
export type ThemeMode = 'system' | 'light' | 'dark'

const key = 'codeatlas.theme'
const darkQuery = '(prefers-color-scheme: dark)'

export function readMode(): ThemeMode {
  try {
    const value = localStorage.getItem(key)
    return value === 'light' || value === 'dark' ? value : 'system'
  } catch {
    return 'system'
  }
}

export function saveMode(mode: ThemeMode) {
  try {
    if (mode === 'system') localStorage.removeItem(key)
    else localStorage.setItem(key, mode)
  } catch {
    // Storage blocked (private window): the choice lasts until reload.
  }
}

export const nextMode = (mode: ThemeMode): ThemeMode => (mode === 'system' ? 'light' : mode === 'light' ? 'dark' : 'system')

export function useTheme() {
  const [mode, setMode] = useState<ThemeMode>(readMode)
  const [systemDark, setSystemDark] = useState(() => window.matchMedia(darkQuery).matches)

  useEffect(() => {
    const query = window.matchMedia(darkQuery)
    const onChange = (event: MediaQueryListEvent) => setSystemDark(event.matches)
    query.addEventListener('change', onChange)
    return () => query.removeEventListener('change', onChange)
  }, [])

  const dark = mode === 'dark' || (mode === 'system' && systemDark)
  useEffect(() => {
    document.documentElement.classList.toggle('dark', dark)
  }, [dark])

  const cycle = useCallback(() => {
    setMode(current => {
      const next = nextMode(current)
      saveMode(next)
      return next
    })
  }, [])

  return { mode, dark, cycle }
}
```

```ts
/** Milliseconds between a span start and the trace origin, computed in BigInt so nanoseconds are not rounded away. */
export function offsetMs(startUnixNano: string, origin: bigint): number {
  return Number(BigInt(startUnixNano) - origin) / 1_000_000
}

export function formatMs(ms: number): string {
  return ms >= 1000 ? `${(ms / 1000).toFixed(2)} s` : `${ms.toFixed(1)} ms`
}

const pad = (n: number, width = 2) => String(n).padStart(width, '0')

/** Local wall-clock time of a nanosecond timestamp. */
export function clock(unixNano: string, withMs = false): string {
  const date = new Date(Number(BigInt(unixNano) / 1_000_000n))
  const base = `${pad(date.getHours())}:${pad(date.getMinutes())}:${pad(date.getSeconds())}`
  return withMs ? `${base}.${pad(date.getMilliseconds(), 3)}` : base
}
```

```ts
export const MAX_TRACES = 500

function newestFirst(a: TraceSummary, b: TraceSummary): number {
  const difference = BigInt(b.startUnixNano) - BigInt(a.startUnixNano)
  return difference > 0n ? 1 : difference < 0n ? -1 : a.traceId.localeCompare(b.traceId)
}

/** Newest first. A summary for a known trace replaces the older copy: spans of a trace keep arriving. */
export function mergeSummaries(current: TraceSummary[], incoming: TraceSummary[]): TraceSummary[] {
  const byId = new Map(current.map(s => [s.traceId, s]))
  for (const summary of incoming) byId.set(summary.traceId, summary)
  return [...byId.values()].sort(newestFirst).slice(0, MAX_TRACES)
}

/** The collector fills method, route and status from the trace's server span. */
export const hasServer = (s: TraceSummary) => s.method !== null || s.route !== null || s.statusCode !== null

/** Follow mode shows the newest trace that reached the backend (spec §8). */
export function followTarget(list: TraceSummary[]): string | null {
  return list.find(hasServer)?.traceId ?? null
}

export function matches(s: TraceSummary, filter: string): boolean {
  const term = filter.trim().toLowerCase()
  if (!term) return true
  return [s.interaction, s.method, s.route, s.statusCode?.toString(), s.traceId].some(value => value?.toLowerCase().includes(term))
}

  if (s.hasError || (s.statusCode ?? 0) >= 500) return 'error'
```

`src/viewer/src/model/tree.ts`:
```ts
import type { NodeView } from '@/api/types'
import { offsetMs } from './time'

export interface Row {
  node: NodeView
  depth: number
  hasChildren: boolean
  offsetMs: number
  durationMs: number
  error: boolean
  slow: boolean
}

function* walk(nodes: NodeView[]): Generator<NodeView> {
  for (const node of nodes) {
    yield node
    yield* walk(node.children)
  }
}

export function traceOrigin(roots: NodeView[]): bigint {
  let origin: bigint | undefined
  for (const node of walk(roots)) {
    const start = BigInt(node.span.startUnixNano)
    if (origin === undefined || start < origin) origin = start
  }
  return origin ?? 0n
}

export function totalMs(roots: NodeView[], origin: bigint): number {
  let end = origin
  for (const node of walk(roots)) {
    const value = BigInt(node.span.endUnixNano)
    if (value > end) end = value
  }
  return Number(end - origin) / 1_000_000
}

export function isError(node: NodeView): boolean {
  const status = Number(node.span.attributes['http.response.status_code'] ?? 0)
  return node.span.status === 'error' || status >= 500 || node.span.events.some(e => e.name === 'exception')
}

const byStart = (a: NodeView, b: NodeView) => {
  const difference = BigInt(a.span.startUnixNano) - BigInt(b.span.startUnixNano)
  return difference < 0n ? -1 : difference > 0n ? 1 : 0
}

/** Pre-order rows, children in start order; collapsed nodes keep their row but hide descendants. */
export function rows(roots: NodeView[], collapsed: ReadonlySet<string>, slowMs: number): Row[] {
  const origin = traceOrigin(roots)
  const result: Row[] = []
  const visit = (nodes: NodeView[], depth: number) => {
    for (const node of [...nodes].sort(byStart)) {
      result.push({
        node,
        depth,
        hasChildren: node.children.length > 0,
        offsetMs: offsetMs(node.span.startUnixNano, origin),
        durationMs: node.span.durationMs,
        error: isError(node),
        slow: node.span.durationMs >= slowMs,
      })
      if (!collapsed.has(node.span.spanId)) visit(node.children, depth + 1)
    }
  }
  visit(roots, 0)
  return result
}

export function findNode(roots: NodeView[], spanId: string): NodeView | undefined {
  for (const node of walk(roots)) if (node.span.spanId === spanId) return node
  return undefined
}

/** The chain from a root down to the node's parent. Empty for roots. */
export function ancestors(roots: NodeView[], spanId: string): NodeView[] {
  const search = (nodes: NodeView[], path: NodeView[]): NodeView[] | undefined => {
    for (const node of nodes) {
      if (node.span.spanId === spanId) return path
      const found = search(node.children, [...path, node])
      if (found) return found
    }
    return undefined
  }
  return search(roots, []) ?? []
}

/** The first executed method if there is one (what the developer usually wants), else the first server span, else the first root. */
export function defaultSelection(roots: NodeView[]): string | undefined {
  const all = [...walk(roots)]
  return (all.find(n => n.code?.evidence === 'executed') ?? all.find(n => n.kind === 'server') ?? all[0])?.span.spanId
}
```

```tsx
import { ChevronRight, TriangleAlert } from 'lucide-react'
import { useState, type KeyboardEvent } from 'react'
import type { TraceView } from '@/api/types'
import { Badge } from '@/components/ui/badge'
import { ScrollArea } from '@/components/ui/scroll-area'
import { cn } from '@/lib/utils'
import { formatMs } from '@/model/time'
import { rows, totalMs, traceOrigin, type Row } from '@/model/tree'
import { CorrelationBadge, GapNote, KindTag, RoutingChip } from './badges'

const MAX_INDENT_LEVELS = 24
const columns = 'grid grid-cols-[minmax(0,1fr)_minmax(140px,36%)_72px] gap-x-3'

export function ExecutionTree({ view, selected, onSelect, slowMs }: {
  view: TraceView
  selected: string | null
  onSelect: (spanId: string) => void
  slowMs: number
}) {
  const [collapsed, setCollapsed] = useState<ReadonlySet<string>>(() => new Set())
  const total = Math.max(totalMs(view.roots, traceOrigin(view.roots)), 0.001)
  const list = rows(view.roots, collapsed, slowMs)
  const toggle = (spanId: string) =>
    setCollapsed(current => {
      const next = new Set(current)
      if (next.has(spanId)) next.delete(spanId)
      else next.add(spanId)
      return next
    })

  return (
    <div className="flex min-h-0 flex-1 flex-col">
      <Legend />
      <div className={cn(columns, 'border-b px-4 py-1.5 text-xs text-muted-foreground')}>
        <span>Span</span>
        <span className="flex justify-between font-mono">
          {[0, 0.25, 0.5, 0.75, 1].map(f => (
            <span key={f}>{f === 1 ? `${Math.round(total)} ms` : Math.round(total * f)}</span>
          ))}
        </span>
        <span className="text-right">Duration</span>
      </div>
      <ScrollArea className="min-h-0 flex-1">
        <div role="tree" aria-label="Execution tree" className="py-1">
          {list.map(row => (
            <TreeRow
              key={row.node.span.spanId}
              row={row}
              total={total}
              selected={row.node.span.spanId === selected}
              collapsed={collapsed.has(row.node.span.spanId)}
              onToggle={toggle}
              onSelect={onSelect}
            />
          ))}
        </div>
      </ScrollArea>
    </div>
  )
}

function Legend() {
  return (
    <div aria-label="Evidence legend" className="flex flex-wrap items-center gap-x-4 gap-y-1 border-b px-4 py-2 text-xs text-muted-foreground">
      <span className="flex items-center gap-1.5">
        <span className="h-2 w-4 rounded-sm bg-bar" aria-hidden />
        Executed

        <Badge variant="outline" className="border-routing/40 bg-routing-soft text-routing">route</Badge>
        Routing metadata
      </span>

        Linked by timing
      </span>

        Not visible
      </span>
    </div>
  )

function TreeRow({ row, total, selected, collapsed, onToggle, onSelect }: {
  row: Row
  total: number
  selected: boolean
  collapsed: boolean
  onToggle: (spanId: string) => void
  onSelect: (spanId: string) => void
}) {
  const { node } = row
  const spanId = node.span.spanId
  const heuristic = node.correlation === 'heuristic'
  const onKeyDown = (event: KeyboardEvent) => {
    if (event.key === 'Enter' || event.key === ' ') {
      event.preventDefault()
      onSelect(spanId)
    }
  }

  return (
    <div
      role="treeitem"
      tabIndex={0}
      data-span-id={spanId}
      aria-level={row.depth + 1}
      aria-selected={selected}
      aria-expanded={row.hasChildren ? !collapsed : undefined}
      onClick={() => onSelect(spanId)}
      onKeyDown={onKeyDown}
      className={cn(columns, 'cursor-pointer items-start px-4 py-1 text-sm outline-none hover:bg-accent/60 focus-visible:bg-accent', selected && 'bg-accent')}
    >
      <div className="min-w-0" style={{ paddingLeft: Math.min(row.depth, MAX_INDENT_LEVELS) * 16 }}>
        <div className={cn('flex min-w-0 items-center gap-1.5', heuristic && 'border-l border-dashed border-heuristic pl-1.5')}>
          {row.hasChildren ? (
            <button
              type="button"
              aria-label={collapsed ? 'Expand' : 'Collapse'}
              onClick={event => {
                event.stopPropagation()
                onToggle(spanId)
              }}
              className="text-muted-foreground hover:text-foreground"
            >
              <ChevronRight className={cn('size-3.5 transition-transform', !collapsed && 'rotate-90')} />
            </button>
          ) : (
            <span className="w-3.5 shrink-0" />
          )}
          <KindTag kind={node.kind} />
          <span className={cn('truncate', row.error && 'text-error')} title={node.span.name}>
            {node.span.name}
          </span>
          {node.code?.evidence === 'routing' && <RoutingChip fn={node.code.function} />}
          {heuristic && <CorrelationBadge kind="heuristic" />}
          {row.error && (
            <Badge variant="outline" className="border-error/40 text-error">
              error
            </Badge>
          )}
        </div>
        {node.gaps.map(gap => (
          <div key={gap.kind} className="pl-5">
            <GapNote gap={gap} />
          </div>
        ))}
      </div>
      <div className="relative mt-1.5 h-2.5" aria-hidden>
        <div
          className={cn('absolute h-full rounded-sm', row.error ? 'bg-error' : row.slow ? 'bg-slow' : 'bg-bar', heuristic && 'outline-1 outline-dashed outline-heuristic')}
          style={{ left: `${(row.offsetMs / total) * 100}%`, width: `max(2px, ${(row.durationMs / total) * 100}%)` }}
        />
      </div>
      <span className={cn('text-right font-mono text-xs', row.slow ? 'text-slow' : 'text-muted-foreground')}>
        {formatMs(row.durationMs)}
        {row.slow && <span className="sr-only"> (slow)</span>}
      </span>
    </div>
  )
}
```

```tsx
import { Fragment, type ReactNode } from 'react'
import type { CodeRef, CollectorInfo, NodeView, SpanEvent, TraceView } from '@/api/types'
import { Badge } from '@/components/ui/badge'
import { ScrollArea } from '@/components/ui/scroll-area'
import { cn } from '@/lib/utils'
import { clock, formatMs } from '@/model/time'
import { ancestors, findNode, isError } from '@/model/tree'
import { CorrelationBadge, GapNote, KindTag, RoutingChip } from './badges'

export function Inspector({ view, spanId, info, dark, onSelect }: {
  view: TraceView | null
  spanId: string | null
  info: CollectorInfo | null
  dark: boolean
  onSelect: (spanId: string) => void
}) {
  const node = view && spanId ? findNode(view.roots, spanId) : undefined
  if (!view || !node) {
    return (
      <aside aria-label="Inspector" className="p-6 text-sm text-muted-foreground">
        Select a span to see what it recorded.
      </aside>
    )
  }
  const span = node.span
  const parent = span.parentSpanId ? findNode(view.roots, span.parentSpanId) : undefined
  // Only a method that is recorded as executed is named as where this span ran.
  const owner = ancestors(view.roots, span.spanId).reverse().find(a => a.code?.evidence === 'executed')

  return (
    <aside aria-label="Inspector" className="flex min-h-0 flex-col">
      <ScrollArea className="min-h-0 flex-1">
        <div className="space-y-5 p-4">
          <div className="space-y-1.5">
            <div className="flex flex-wrap items-center gap-1.5">
              <KindTag kind={node.kind} />
              <Badge variant="outline" className="border-executed/40 text-executed">executed</Badge>
              {node.code?.evidence === 'routing' && <RoutingChip fn={node.code.function} />}
              {node.correlation && <CorrelationBadge kind={node.correlation} />}
              {isError(node) && <Badge variant="outline" className="border-error/40 text-error">error</Badge>}
            </div>
            <h2 className="break-words font-mono text-sm font-medium">{node.code?.function ?? span.name}</h2>
          </div>

          <dl className="grid grid-cols-[96px_minmax(0,1fr)] gap-x-3 gap-y-1.5 text-xs">
            <Fact label="Duration">{formatMs(span.durationMs)}</Fact>
            <Fact label="Start → end">{clock(span.startUnixNano, true)} → {clock(span.endUnixNano, true)}</Fact>
            <Fact label="Trace" mono>{span.traceId}</Fact>
            <Fact label="Span" mono>{span.spanId}</Fact>
            <Fact label="Parent" mono>
              {!span.parentSpanId ? (
                'root'
              ) : parent ? (
                <button type="button" className="underline underline-offset-2" onClick={() => onSelect(parent.span.spanId)}>
                  {span.parentSpanId}
                </button>
              ) : (
                `${span.parentSpanId} (not received)`
              )}
            </Fact>
            <Fact label="Service">{`${span.service} · ${span.scope}`}</Fact>
            <Fact label="Status">{span.statusMessage ? `${span.status}: ${span.statusMessage}` : span.status}</Fact>
          </dl>

          {node.gaps.length > 0 && (
            <section aria-label="Visibility" className="space-y-1">
              {node.gaps.map(gap => <GapNote key={gap.kind} gap={gap} />)}
            </section>
          )}

          {span.events.filter(e => e.name === 'exception').map((event, i) => <ExceptionBlock key={i} event={event} />)}

          <section aria-label="Source">
            {node.code ? <MethodIdentity code={node.code} /> : <NoSource node={node} owner={owner} onSelect={onSelect} />}
          </section>

          <Attributes attributes={span.attributes} />
        </div>
      </ScrollArea>
      <span className="sr-only">{dark ? 'dark theme' : 'light theme'}</span>
      <span className="sr-only">{info?.editor.kind}</span>
    </aside>
  )
}

function Fact({ label, mono, children }: { label: string; mono?: boolean; children: ReactNode }) {
  return (
    <>
      <dt className="text-muted-foreground">{label}</dt>
      <dd className={cn('break-all', mono && 'font-mono')}>{children}</dd>
    </>
  )
}

function MethodIdentity({ code }: { code: CodeRef }) {
  return (
    <p className="text-xs text-muted-foreground">
      {code.evidence === 'routing' ? 'Route target (routing metadata): ' : 'Executed method: '}
      <span className="font-mono text-foreground">{code.function}</span>
    </p>
  )
}

function NoSource({ node, owner, onSelect }: { node: NodeView; owner: NodeView | undefined; onSelect: (spanId: string) => void }) {
  return (
    <div className="space-y-2 text-xs text-muted-foreground">
      <p>
        {node.kind === 'database'
          ? 'A database operation has no method identity, so there is no source to show.'
          : 'This span has no method identity, so there is no source to show.'}
        {owner && (
          <>
            {' It ran inside '}
            <button type="button" className="font-mono text-foreground underline underline-offset-2" onClick={() => onSelect(owner.span.spanId)}>
              {owner.code!.function}
            </button>
            ; select it to see its code.
          </>
        )}
      </p>
      {node.kind === 'database' && <p>SQL text, parameters and connection details are never exported.</p>}
    </div>
  )
}

function ExceptionBlock({ event }: { event: SpanEvent }) {
  const a = event.attributes
  const stack = a['exception.stacktrace']
  return (
    <section aria-label="Exception" className="space-y-1.5 rounded-md border border-error/40 bg-error-soft p-3">
      <p className="font-mono text-xs font-medium text-error">{String(a['exception.type'] ?? 'Exception')}</p>
      {a['exception.message'] != null && <p className="text-sm">{String(a['exception.message'])}</p>}
      {stack != null && (
        <>
          <pre className="max-h-48 overflow-auto whitespace-pre-wrap font-mono text-[11px] text-muted-foreground">{String(stack)}</pre>
          <p className="text-xs text-muted-foreground">Methods without a span of their own appear only as frames in this recorded stack trace.</p>
        </>
      )}
    </section>
  )
}

function Attributes({ attributes }: { attributes: Record<string, unknown> }) {
  const entries = Object.entries(attributes).sort(([a], [b]) => a.localeCompare(b))
  if (entries.length === 0) return null
  return (
    <section aria-label="Attributes">
      <h3 className="mb-1.5 text-xs font-medium text-muted-foreground">Attributes</h3>
      <dl className="grid grid-cols-[minmax(0,42%)_minmax(0,1fr)] gap-x-3 gap-y-1 font-mono text-[11px]">
        {entries.map(([key, value]) => (
          <Fragment key={key}>
            <dt className="truncate text-muted-foreground" title={key}>{key}</dt>
            <dd className="break-all">{typeof value === 'string' ? value : JSON.stringify(value)}</dd>
          </Fragment>
        ))}
      </dl>
    </section>
  )
}
```

```tsx
import { ArrowRight } from 'lucide-react'
import { useCallback, useEffect, useRef, useState } from 'react'
import { getInfo, getTrace, getTraces } from '@/api/client'
import { signalRLive, type LiveSource, type LiveState } from '@/api/live'
import type { CollectorInfo, TraceSummary, TraceView } from '@/api/types'
import { ActivityList } from '@/components/ActivityList'
import { CorrelationBadge, StatusText } from '@/components/badges'
import { ExecutionTree } from '@/components/ExecutionTree'
import { Inspector } from '@/components/Inspector'
import { TopBar } from '@/components/TopBar'
import { followTarget, hasServer, mergeSummaries } from '@/model/activity'
import { formatMs, shortId } from '@/model/time'
import { defaultSelection, findNode } from '@/model/tree'
import { useTheme } from '@/theme'

export const DEFAULT_SLOW_MS = 200

function slowFromUrl(): number {
  const value = Number(new URLSearchParams(location.search).get('slow'))
  return Number.isFinite(value) && value > 0 ? value : DEFAULT_SLOW_MS
}

export function App({ live = signalRLive }: { live?: LiveSource }) {
  const theme = useTheme()
  const [slowMs] = useState(slowFromUrl)
  const [info, setInfo] = useState<CollectorInfo | null>(null)
  const [summaries, setSummaries] = useState<TraceSummary[]>([])
  const [liveState, setLiveState] = useState<LiveState>('connecting')
  const [follow, setFollow] = useState(true)
  const [filter, setFilter] = useState('')
  const [traceId, setTraceId] = useState<string | null>(null)
  const [view, setView] = useState<TraceView | null>(null)
  const [missing, setMissing] = useState(false)
  const [spanId, setSpanId] = useState<string | null>(null)
  const [refresh, setRefresh] = useState(0)
  const [error, setError] = useState<string | null>(null)
  const selected = useRef<string | null>(null)
  selected.current = traceId

  const reload = useCallback(() => {
    getTraces().then(
      list => {
        setError(null)
        setSummaries(current => mergeSummaries(current, list))
      },
      (e: Error) => setError(`Could not load traces: ${e.message}`),
    )
  }, [])

  useEffect(() => {
    getInfo().then(setInfo, () => setInfo(null))
    reload()
  }, [reload])

  useEffect(
    () =>
      live.start(
        updates => {
          setSummaries(current => mergeSummaries(current, updates))
          if (updates.some(u => u.traceId === selected.current)) setRefresh(n => n + 1)
        },
        state => {
          setLiveState(state)
          // Updates may have been missed while disconnected.
          if (state === 'live') reload()
        },
      ),
    [live, reload],
  )

  useEffect(() => {
    if (!follow) return
    const target = followTarget(summaries)
    if (target && target !== selected.current) {
      setTraceId(target)
      setSpanId(null)
    }
  }, [follow, summaries])

  useEffect(() => {
    if (!traceId) return
    let current = true
    getTrace(traceId).then(
      next => {
        if (!current) return
        setView(next)
        setMissing(next === null)
        setSpanId(previous => (next && previous && findNode(next.roots, previous) ? previous : next ? defaultSelection(next.roots) ?? null : null))
      },
      (e: Error) => current && setError(`Could not load trace: ${e.message}`),
    )
    return () => {
      current = false
    }
  }, [traceId, refresh])

  const choose = (id: string) => {
    setFollow(false)
    setTraceId(id)
    setSpanId(null)
  }

  const shown = view && view.summary.traceId === traceId ? view : null

  return (
    <div className="flex h-screen flex-col bg-background text-foreground">
      <TopBar info={info} liveState={liveState} follow={follow} onFollow={setFollow} mode={theme.mode} onCycleMode={theme.cycle} />
      {error && (
        <p role="alert" className="border-b bg-error-soft px-4 py-1.5 text-xs text-error">
          {error}
        </p>
      )}
      <div className="grid min-h-0 flex-1 grid-cols-[300px_minmax(0,1fr)_420px]">
        <ActivityList summaries={summaries} selected={traceId} filter={filter} onFilter={setFilter} onSelect={choose} />
        <main aria-label="Trace" className="flex min-h-0 flex-col border-x">
          {shown ? (
            <>
              <TraceHeader summary={shown.summary} truncated={shown.truncated} />
              <ExecutionTree key={shown.summary.traceId} view={shown} selected={spanId} onSelect={setSpanId} slowMs={slowMs} />
            </>
          ) : (
            <p className="m-auto max-w-sm p-6 text-center text-sm text-muted-foreground">
              {missing
                ? 'This trace is no longer in the collector (older traces are evicted).'
                : traceId
                  ? 'Loading trace…'
                  : 'No trace selected. Traces that reach your backend are followed automatically.'}
            </p>
          )}
        </main>
        <Inspector view={shown} spanId={spanId} info={info} dark={theme.dark} onSelect={setSpanId} />
      </div>
    </div>
  )
}

function TraceHeader({ summary, truncated }: { summary: TraceSummary; truncated: boolean }) {
  return (
    <div className="border-b">
      <div className="flex flex-wrap items-center gap-x-3 gap-y-1 px-4 py-3">
        <span className="font-medium">{summary.interaction ?? 'No interaction'}</span>
        {summary.correlation && <CorrelationBadge kind={summary.correlation} />}
        <ArrowRight className="size-4 text-muted-foreground" aria-hidden />
        <span className="font-mono text-sm">{hasServer(summary) ? `${summary.method ?? ''} ${summary.route ?? ''}`.trim() : 'no server span'}</span>
        <StatusText summary={summary} />
        <span className="text-sm text-muted-foreground">
          {formatMs(summary.durationMs)} · {summary.spanCount} spans
        </span>
        <span className="ml-auto font-mono text-xs text-muted-foreground" title={summary.traceId}>
          {shortId(summary.traceId)}
        </span>
      </div>
      {truncated && <p className="px-4 pb-2 text-xs text-gap">This trace reached the span limit; later spans were dropped.</p>}
    </div>
  )
}
```

```tsx
export default function MonacoView({ text, displayStart, displayEnd, navigationLine, executableLines, dark }: MonacoViewProps) {
  const host = useRef<HTMLDivElement>(null)
  const editor = useRef<monaco.editor.IStandaloneCodeEditor | null>(null)

  useEffect(() => {
    const instance = monaco.editor.create(host.current!, {
      value: text,
      language: 'csharp',
      readOnly: true,
      domReadOnly: true,
      minimap: { enabled: false },
      scrollBeyondLastLine: false,
      automaticLayout: true,
      glyphMargin: true,
      renderLineHighlight: 'none',
      fontFamily: "'Geist Mono Variable', ui-monospace, monospace",
      fontSize: 12,
      lineHeight: 19,
      theme: dark ? 'codeatlas-dark' : 'codeatlas-light',
    })
    editor.current = instance
    return () => {
      instance.getModel()?.dispose()
      instance.dispose()
      editor.current = null
    }
    // The editor is recreated only for new text; theme and highlights update in place below.
  }, [text]) // eslint-disable-line react-hooks/exhaustive-deps

  useEffect(() => {
    monaco.editor.setTheme(dark ? 'codeatlas-dark' : 'codeatlas-light')
  }, [dark])

  useEffect(() => {
    const instance = editor.current
    if (!instance) return
    const decorations = instance.createDecorationsCollection([
      { range: new monaco.Range(displayStart, 1, displayEnd, 1), options: { isWholeLine: true, className: 'ca-declaration' } },
      ...executableLines.map(line => ({
        range: new monaco.Range(line, 1, line, 1),
        options: { glyphMarginClassName: 'ca-executable', glyphMarginHoverMessage: { value: 'Executable line (from the PDB)' } },
      })),
    ])
    instance.revealLineNearTop(navigationLine)
    instance.setPosition({ lineNumber: navigationLine, column: 1 })
    return () => decorations.clear()
  }, [text, displayStart, displayEnd, navigationLine, executableLines])

  return <div ref={host} className="h-full w-full" />
}
```

```tsx
import { Copy, ExternalLink } from 'lucide-react'
import { lazy, Suspense, useEffect, useState } from 'react'
import { getSource, openInEditor } from '@/api/client'
import type { CodeRef, CollectorInfo, SourceLocation, SourceResponse } from '@/api/types'
import { Button } from '@/components/ui/button'
import { cn } from '@/lib/utils'

// Monaco is large: it loads only when a source panel is shown.
const MonacoView = lazy(() => import('./MonacoView'))

export function editorName(kind?: string): string {
  return kind === 'vscode' ? 'VS Code' : kind === 'rider' ? 'Rider' : (kind ?? 'editor')
}

export function describeSource(code: CodeRef, location: SourceLocation): string {
  const evidence = code.evidence === 'routing'
    ? 'Routing metadata: the route points here; whether it ran is not recorded'
    : 'Executed method'
  const mapping = location.mapping === 'pdb only' ? 'mapped by PDB only (declaration not found)' : 'mapped by PDB + Roslyn'
  return [evidence, mapping, location.kind, location.stateMachine ? 'async or iterator' : null].filter(Boolean).join(' · ')
}

type State = { status: 'loading' } | { status: 'loaded'; source: SourceResponse } | { status: 'failed'; message: string }
type Notice = { tone: 'ok' | 'error'; text: string }

export function SourcePanel({ code, info, dark }: { code: CodeRef; info: CollectorInfo | null; dark: boolean }) {
  const [state, setState] = useState<State>({ status: 'loading' })
  const [notice, setNotice] = useState<Notice | null>(null)
  const identity = `${code.assembly}|${code.mvid}|${code.token}`

  useEffect(() => {
    let current = true
    setState({ status: 'loading' })
    setNotice(null)
    getSource(code).then(
      source => current && setState({ status: 'loaded', source }),
      (e: Error) => current && setState({ status: 'failed', message: e.message }),
    )
    return () => {
      current = false
    }
    // Refetch only when the identity changes, not when an equal object arrives with a refreshed trace.
  }, [identity]) // eslint-disable-line react-hooks/exhaustive-deps

  if (state.status === 'loading') return <p className="text-xs text-muted-foreground">Loading source…</p>
  if (state.status === 'failed') return <p className="text-xs text-error">Could not load source: {state.message}</p>

  const { location, text } = state.source
  if (!location.found || text === null) {
    return <p className="text-xs text-gap">Source not shown: {location.reason ?? 'the collector gave no reason.'}</p>
  }

  const shownPath = location.relativePath ?? location.file!
  const target = `${location.file}:${location.navigationLine}`
  const editor = editorName(info?.editor.kind)
  const available = info?.editor.available ?? false

  const open = async () => {
    setNotice(null)
    try {
      const result = await openInEditor(code)
      setNotice({ tone: 'ok', text: `Opened ${shownPath}:${result.line} in ${editor}` })
    } catch (e) {
      setNotice({ tone: 'error', text: (e as Error).message })
    }
  }
  const copy = async () => {
    try {
      await navigator.clipboard.writeText(target)
      setNotice({ tone: 'ok', text: `Copied ${target}` })
    } catch {
      setNotice({ tone: 'error', text: `Copy failed. Path: ${target}` })
    }
  }

  return (
    <div className="space-y-2">
      <div className="space-y-0.5">
        <p className="break-all font-mono text-xs">
          <span>{shownPath}</span>
          <span className="text-muted-foreground">:{location.navigationLine}</span>
        </p>
        <p className="text-xs text-muted-foreground">{describeSource(code, location)}</p>
      </div>
      <div className="h-80 overflow-hidden rounded-md border">
        <Suspense fallback={<p className="p-3 text-xs text-muted-foreground">Loading editor…</p>}>
          <MonacoView
            text={text}
            displayStart={location.displayStart}
            displayEnd={location.displayEnd}
            navigationLine={location.navigationLine}
            executableLines={location.executableLines}
            dark={dark}
          />
        </Suspense>
      </div>
      <div className="flex flex-wrap gap-2">
        <Button size="sm" onClick={open} disabled={!available} title={available ? undefined : `${editor} was not found; copy the path instead.`}>
          <ExternalLink />
          Open in {editor}
        </Button>
        <Button size="sm" variant="outline" onClick={copy}>
          <Copy />
          Copy path:line
        </Button>
      </div>
      {info && !available && <p className="text-xs text-muted-foreground">{editor} was not found on this machine; use “Copy path:line”.</p>}
      {notice && (
        <p role="status" className={cn('text-xs', notice.tone === 'error' ? 'text-error' : 'text-success')}>
          {notice.text}
        </p>
      )}
    </div>
  )
}
```

```tsx
  entry: { label: 'entry' },
  request: { label: 'request' },
  executed: { label: 'executed', className: 'border-executed/40 text-executed' },
  routing: { label: 'routing metadata', className: 'border-routing/40 bg-routing-soft text-routing' },
  database: { label: 'database' },
  http: { label: 'http' },
  slowest: { label: 'slowest' },
  exception: { label: 'exception', className: 'border-error/40 text-error' },
  visibility: { label: 'not visible', className: 'border-gap/40 text-gap' },
  sampling: { label: 'sampling', className: 'border-gap/40 text-gap' },
}

export function ExplainView({ view, onSelectSpan }: { view: TraceView; onSelectSpan: (spanId: string) => void }) {

        </p>
```
